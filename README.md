HARRY URL MASKER
================

A simple Python CLI tool that shortens a URL using multiple URL shortener
services and displays the generated masked-style URLs.

Use this tool only for ethical, legal, and authorized purposes.


FEATURES
--------
- Simple command-line interface
- Automatically adds https:// when it is missing
- Uses multiple URL shortener services through pyshorteners
- Displays multiple shortened URLs
- Colored terminal output
- Loading animation
- Handles individual shortener failures without stopping the tool


REQUIREMENTS
------------
- Python 3.x
- Internet connection
- pyshorteners


INSTALLATION
------------

   git clone https://github.com/HarryStrapper07/shadow-urlYOUR-REPOSITORY-URL>

2. Install the required Python package:

USAGE
-----
Run the Python script:

   python <YOUR-SCRIPT-NAME>.py

The tool will ask for:

1. Original URL
2. Custom domain name
3. Keyword

Example:

   Enter the original URL (ex: https://google.com) : https://example.com
   Enter custom domain name (ex: google.com) : example.com
   Enter keyword (ex: login) : login
